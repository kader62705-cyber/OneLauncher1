OneLauncher 2.1 - Galaxy S26 Ultra-inspired Android launcher

A modern, independent launcher with an English-only interface and your supplied OneLauncher logo. Inspired by the clean, premium visual language of recent Galaxy phones; it is not Samsung software.

Included: Android 5.0+ support (minSdk 21), home screen and app drawer, adjustable home/drawer grids, adjustable icon size, dock, app labels toggle, smooth drawer animations, compatible ADW/Nova icon-pack discovery and appfilter drawable mapping, widget picker/host, wallpaper picker, lock-screen/security settings shortcut, appearance preferences, and local layout backup information.

Build: ./gradlew assembleDebug
APK output: app/build/outputs/apk/debug/app-debug.apk

Note: A normal third-party launcher cannot replace Android's secure system lock screen. The Lock Screen option opens the device's supported security settings. Widget availability and icon-pack coverage depend on the device and installed packages.
